# Routes

TanStack Start uses **file-based routing**. Every `.tsx` file in this directory defines a route. Do **not** create `src/pages/`, `src/routes/_app/index.tsx`, or `app/layout.tsx` — those are Next.js / Remix conventions. The only root layout is `src/routes/__root.tsx`.

`routeTree.gen.ts` is auto-generated by TanStack Router. **Do not edit it by hand.**

## Canonical Service Frontdesk IA

The staff application uses capability-oriented URLs. Vertical-specific wording belongs inside the page UI, not in the URL.

| Canonical URL | Capability | Notes |
| --- | --- | --- |
| `/staff/today` | Today | Daily operating dashboard |
| `/staff/inbox` | Conversations | WhatsApp / phone / web inbox |
| `/staff/bookings` | Booking / scheduling | Appointment, vehicle intake, on-site slot, etc. |
| `/staff/workers` | Workers | Worker capability, service area, availability and current jobs |
| `/staff/agent` | Agent work | Service Work Items + legacy bounded Agent tasks |
| `/staff/follow-ups` | Follow-up | Booking reminders, recall and customer reactivation |
| `/staff/customers` | Customers | Customer + Subject + smart migration |
| `/staff/documents` | Administrative data | Forms, quotes, invoices, receipts and adapter-backed records |
| `/staff/staff` | Staff | Roles, invitations and permissions |
| `/staff/audit` | Audit | Human / Agent / system trace |
| `/staff/settings` | Settings | Tenant, Vertical Pack, channels, privacy and integrations |

### Legacy aliases

These URLs are compatibility-only and are canonicalized by `__root.tsx` with `replace` redirects:

| Legacy URL | Canonical URL |
| --- | --- |
| `/staff/appointments` | `/staff/bookings` |
| `/staff/reminders` | `/staff/follow-ups` |
| `/staff/patients` | `/staff/customers` |

Do not add new links to legacy URLs.

## Dental compatibility portal

`/patient/*` remains the **Dental compatibility portal**. It is intentionally separate from the generic Service Frontdesk staff IA until a genuine cross-industry Customer Portal is implemented.

## File-routing conventions

| File | URL |
| --- | --- |
| `index.tsx` | `/` |
| `about.tsx` | `/about` |
| `users/index.tsx` | `/users` |
| `users/$id.tsx` | `/users/:id` |
| `posts/{-$category}.tsx` | `/posts/:category?` |
| `files/$.tsx` | `/files/*` |
| `_layout.tsx` | layout route (renders children via `<Outlet />`) |
| `__root.tsx` | app shell — wraps every page; preserve `<Outlet />` |
